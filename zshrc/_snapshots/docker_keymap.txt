Keymap: docker_keymap.zsh

  `   1   2   3   4   5   |   6   7   8   9   0   [   ] 
      '   ,   .   p   y   |  <f>  g   c   r   l   /   =   \ 
      a  <o>  e  <u>  i   |  <d>  h   t   n  <s>  - 
      ;   q   j   k   x   |   b   m   w   v   z 

  `<>` initials have only one key mapping
  `()` initials have multiple key mappings

Keymap Usage

  $ d                  # Show this keymap
  $ d <regex>          # Search this keymap

  $ d.<key>            # Key takes no variable
  $ d.<key> <var>      # Key takes one variable
  $ d.<key> <var>?     # Key takes zero or one variable
  $ d.<key> <var>*     # Key takes zero or more variables
  $ d.<key> (1-10)     # Key takes a value from inside list
  $ d.<key> (^|)?      # Key can be piped to: ... | d.<key>

     ^                 # The `.` is for visual clarity
                       # Omit it when invoking a key

Keymap List

  $ d <docker command> # Pass through

  $ d.s                # Login with AWS credentials

  $ d.f                # (Reserved: Disk free)
  $ d.o                # (Reserved: Shell keyword)
  $ d.u                # (Reserved: Disk usage)
