Keymap: kiro_keymap.zsh

  `  <1>  2   3   4   5   |   6   7   8   9  <0>  [   ] 
      '   ,   .  (p)  y   |   f   g  <c> <r> <l>  /   =   \ 
     <a>  o   e   u   i   |  <d> <h>  t   n  (s)  - 
      ;   q   j   k   x   |   b  <m>  w   v   z 

  `<>` initials have only one key mapping
  `()` initials have multiple key mappings

Keymap Usage

  $ r              # Show this keymap
  $ r <regex>      # Search this keymap

  $ r.<key>        # Key takes no variable
  $ r.<key> <var>  # Key takes one variable
  $ r.<key> <var>? # Key takes zero or one variable
  $ r.<key> <var>* # Key takes zero or more variables
  $ r.<key> (1-10) # Key takes a value from inside list
  $ r.<key> (^|)?  # Key can be piped to: ... | r.<key>

     ^             # The `.` is for visual clarity
                   # Omit it when invoking a key

Keymap List

  $ r.c            # Start new session
  $ r.r            # Resume last session
  $ r.l            # List previous sessions

  $ r.a            # Agent with Atlassian MCP
  $ r.d            # Agent with Datadog MCP
  $ r.h            # Agent with GitHub MCP
  $ r.s            # Agent with Snowflake MCP
  $ r.ss           # Agent with SDLC MCP

  $ r.M            # Edit config in TextMate (`rm` reserved)
  $ r.p            # Push `kiro` folder to `scratch` repo
  $ r.pp           # Pull `kiro` folder from `scratch` repo

  $ r.0 <command>? # Invoke `kiro-cli` plain
  $ r.1 <command>? # Invoke `kiro-cli` with best model

  $ r.m            # (Reserved: Remove files)
