      '   ,   .   p   y   |   f   g  <c>  r   l   /   =   \ 
     <a>  o   e  <u>  i   |  (d) (h) (t) <n>  s   - 
      ;   q   j   k   x   |   b  <m>  w   v   z 

  `<>` initials have only one key mapping
  `()` initials have multiple key mappings

Keymap Usage

  $ u                 # Show this keymap
  $ u <regex>         # Search this keymap

  $ u.<key>           # Key takes no variable
  $ u.<key> <var>     # Key takes one variable
  $ u.<key> <var>?    # Key takes zero or one variable
  $ u.<key> <var>*    # Key takes zero or more variables
  $ u.<key> (1-10)    # Key takes a value from inside list
  $ u.<key> (^|)?     # Key can be piped to: ... | u.<key>

     ^                # The `.` is for visual clarity
                      # Omit it when invoking a key

Keymap List

  $ u.u <n>?          # Usage overview (Default: All days)

  $ u.n <n OR match>? # Top namespaces (Default: All days)
  $ u.a <n OR match>? # Top aliases (Default: All days)

  $ u.d <n>?          # By day of week (logged zone)
  $ u.dd <n>?         # By day of week (current zone)
  $ u.h <n>?          # By hour of day (logged zone)
  $ u.hh <n>?         # By hour of day (current zone)

  $ u.m               # Open usage in TextMate
  $ u.c               # Clear usage file

  $ u.t <n>           # Backup data, generate test data (n days)
  $ u.tt              # Restore real data from backup
