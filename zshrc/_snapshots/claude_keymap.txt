Keymap: claude_keymap.zsh

  `   1   2   3   4   5   |   6   7   8   9   0   [   ] 
      '   ,   .  <p>  y   |   f   g  <c> <r> <l>  /   =   \ 
      a   o   e  <u>  i   |  <d>  h   t  <n> (s)  - 
      ;   q   j   k   x   |   b  <m>  w   v   z 

  `<>` initials have only one key mapping
  `()` initials have multiple key mappings

Keymap Usage

  $ c              # Show this keymap
  $ c <regex>      # Search this keymap

  $ c.<key>        # Key takes no variable
  $ c.<key> <var>  # Key takes one variable
  $ c.<key> <var>? # Key takes zero or one variable
  $ c.<key> <var>* # Key takes zero or more variables
  $ c.<key> (1-10) # Key takes a value from inside list
  $ c.<key> (^|)?  # Key can be piped to: ... | c.<key>

     ^             # The `.` is for visual clarity
                   # Omit it when invoking a key

Keymap List


  $ c.c            # Start new session
  $ c.r            # Resume last session
  $ c.l <match>?   # List matching sessions

  $ c.s            # Start scratch session
  $ c.ss           # Reset tab background color
  $ c.n            # Start new 5-hour token window

  $ c.m            # Edit config folder in TextMate
  $ c.u            # Push config to `scratch` (`cp` reserved)
  $ c.U            # Pull config from `scratch` repo

  $ c.d            # (Reserved: Change directory)
  $ c.p            # (Reserved: Copy files)
